# CodeAlpha Python Programming Internship — All 4 Tasks

All scripts are tested and run with plain `python3` (standard library only,
except Task 3 Option C which needs `requests`).

## Files

| File | Task | Run |
|---|---|---|
| `hangman.py` | Task 1 — Hangman Game | `python3 hangman.py` |
| `stock_portfolio_tracker.py` | Task 2 — Stock Portfolio Tracker | `python3 stock_portfolio_tracker.py` |
| `task3_move_jpg_files.py` | Task 3, Option A — move .jpg files | `python3 task3_move_jpg_files.py` |
| `task3_extract_emails.py` | Task 3, Option B — extract emails from a .txt | `python3 task3_extract_emails.py` |
| `task3_scrape_title.py` | Task 3, Option C — scrape a webpage title (`pip install requests`) | `python3 task3_scrape_title.py` |
| `chatbot.py` | Task 4 — Basic Chatbot | `python3 chatbot.py` |

For Task 3, submit **one** of the three options (the internship instructions
say to pick one idea) — Option B (`task3_extract_emails.py`) is the simplest
to demo since it needs no internet or extra folders.

## Submission checklist (per the internship instructions)

1. Post your internship status on LinkedIn, tagging **@CodeAlpha**.
2. Create a **separate GitHub repo per task**, named `CodeAlpha_ProjectName`
   (e.g. `CodeAlpha_HangmanGame`, `CodeAlpha_StockPortfolioTracker`,
   `CodeAlpha_TaskAutomation`, `CodeAlpha_Chatbot`).
3. Record a short video walking through each project and post it on
   LinkedIn with the GitHub repo link.
4. Submit via the Submission Form shared in your WhatsApp group.
5. You only need to complete **2–3** of these 4 tasks for the certificate —
   all four are included here so you can choose your favorites.

## Notes

- Each script is self-contained and uses only console input/output.
- `stock_portfolio_tracker.py` can save a summary to `.txt` and `.csv`.
- `hangman.py` and `chatbot.py` use only the standard library.
